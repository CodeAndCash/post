# Бот для постов с кнопками (миниапп)

Бот присылает в личку сообщение с кнопкой «Войти». В миниаппе ты добавляешь медиа, текст и кнопки,
бот отправляет готовый пост тебе в чат, а ты пересылаешь его в канал.

Переменные: BOT_TOKEN, WEBAPP_URL (адрес на Railway со `/` в конце), ADMIN_IDS (твой Telegram ID), PORT=8080.
Запуск: `pip install -r requirements.txt && python bot.py`. Проверка сервера: открой `WEBAPP_URL` + `health`, должно быть «ok».
